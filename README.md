# Kashish Srivastava | Portfolio

A neo-brutalist personal portfolio for a **MERN Stack Developer**, **Frontend Developer** and **Data Analyst**, with a role switcher that changes the page colour, tagline, skills and CV link.

**Live:** https://kashish706.github.io/My_Portfolio/

## Features

- **Role switcher:** MERN Stack, Frontend and Data Analyst views, each with its own colour theme and tagline
- **Project filter:** filter projects by role (All, MERN Stack, Frontend, Data Analyst)
- **Neo-brutalist design:** bold borders, hard shadows and a marquee strip
- **Responsive:** works on mobile, tablet and desktop
- **Sections:** Hero, About, Skills, Projects, Training & Certifications, Education, Achievements, Contact

## Built with

HTML5 · CSS3 · Bootstrap 5 · JavaScript

## Run locally

```bash
git clone https://github.com/kashish706/My_Portfolio.git
cd My_Portfolio
```

Open `index.html` in your browser. No build step or installation is needed.
